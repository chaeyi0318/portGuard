## 2026-10-26 MQTT 실제 브로커 검증

Codex가 Docker Mosquitto, MQTT worker·sender와 기존 Atlas 사건으로 확인했습니다.

- 기존 사건 a10354ea-3c43-4e74-9d03-7314b3301248의 JSON·JPEG를 실제 MQTT로 전송.
- 서버 저장 ACK 수신 및 로컬 `.acked` 파일 생성 확인.
- DB에서 동일 eventId 사건 수 1건 유지 확인(기존 사건 재전송 경로).
- 별도 Python 프로세스에서 영속 ACK를 읽고 재전송하지 않는 것을 확인.
- Flask 5001번 증거 API: 200 image/jpeg, 41,714 bytes.
- 기존 DB 인덱스 이름과 worker 생성 이름 충돌을 수정.
- 자동 테스트 12개 통과. 신규 사건 최초 저장·DB 실패·잘못된 JPEG는 모의 DB 자동 테스트로 검증.
