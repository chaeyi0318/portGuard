# 작업 진행 상황

기준일: 2026-10-25. 저장소 코드와 대화에서 공유된 실행 결과를 기준으로 합니다.
문서 정리 시 실제 DB 쓰기·영상 재실행·자동 테스트는 수행하지 않았습니다.

## 영상 처리

| 작업 | 상태·근거 |
|---|---|
| CAVIAR 영상 확보·재생 | Browse1/2, Walk1/2 확보. Browse2로 실행 확인 |
| YOLO 감지·추적 | yolo11s + ByteTrack 구현. ID 40 안팎 표시 확인 |
| ROI·박스·발밑 점 | 표시·안팎 판정 확인. 경계는 내부 취급 |
| 체류 2초 | 영상 22.52초에서 누적 2.00초 사건 신호 출력 확인 |
| 누락 유예 0.5초 | 구현·사용자 실행 확인. 상세 수치 검증 미완료 |
| 퇴장 확인 1초 | 구현·사용자 실행 확인. 상세 시나리오 검증 미완료 |
| 지속 체류 반복 방지 | 같은 ID 기준 1회 출력 확인 |
| 퇴장 후 재진입 | 코드 있음. 두 번째 사건 발생 별도 검증 필요 |
| 분석 중단 시간 제외 | 파일 프레임/FPS 사용. 명시적 중단·재개 검증 필요 |
| 증거 이미지 생성 | 미구현 |
| 웹캠 | 미구현. 현재 코드는 파일 경로를 사용 |
| 성능 평가·출처 문서 | 정리 시작. 구간별 예상·실측 비교 미완료 |

알려진 문제: 의자 오탐, 추적 ID 변경 가능성. 현재 중복 방지는 동일 ID에 한정됩니다.
체류 신호는 콘솔 출력뿐이며 실제 사건 DB 저장과 연결되지 않았습니다.
검출 누락 시 내부 누적은 유예 동안 보존하고 누락 시간은 더하지 않습니다.
사건 발생 표식은 누락으로 해제하지 않으며 확인된 퇴장 때 해제합니다.

실제 응답 JSON·영상 헤더·이벤트 계약의 호환은 확인되지 않았습니다.
DB는 영속 저장이지만 프로세스 재시작 전후 사건·이력 조회를 별도로 검증해야 합니다.

## 가상 장비·MQTT

기존 대화 현황과 달리 현재 저장소에는 가상 경광등 구현이 추가되어 있습니다.

- BEACON-01 에이전트, 3초 heartbeat, worker의 10초 연결 끊김 판정 코드
- 명령 queued/sent/accepted/succeeded/failed/timed_out 처리와 재전송
- 세션·sequence 검사, SQLite 명령 중복 방지, MongoDB 상태·이력 저장 코드
- 장비·명령·이력 API, 브로커 compose, 자동 테스트 파일

위 항목은 코드 확인 기준입니다. 이번 정리에서는 테스트를 실행하지 않았으며
실제 브로커·Atlas를 사용한 통합 실행 결과는 별도 기록이 필요합니다.
제한과 실행 방법은 [beacon.md](beacon.md)를 참고합니다.

미구현: CAM-01 MQTT 사건·ACK·outbox, CAM-01 독립 heartbeat·6개 상태,
LWT/retained 상태 처리, 부저·게이트, 점검, 침입→경광등 자동 명령 연결.
후속 센서·비상정지·게이트웨이·배터리도 미구현입니다.

## 유지할 원칙

구역 상태, 사건 처리, CAM-01 상태, 점검 상태를 분리합니다.
퇴장·장비 복구가 기존 사건을 자동 종료하지 않습니다.
관측 중단을 clear로 표시하지 않습니다. 연결 끊김의 물리적 원인을 단정하지 않습니다.
MongoDB 정보는 서버에서만 사용하며 QuayPilot 소스·에셋 없이 독립 실행을 유지합니다.
